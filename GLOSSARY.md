# Markora

A markdown editor for desktop and web. This glossary covers the vocabulary of first-run onboarding.

## Onboarding

**Tour**:
The guided, step-by-step walkthrough of the app's main areas, shown over the real interface.
_Avoid_: Walkthrough, tutorial, onboarding flow

**Tour stop**:
One step of the Tour, anchored to a single area of the interface.
_Avoid_: Slide, page

**Tour prompt**:
The one-time "Take a quick tour?" invitation that lets a user accept the Tour or skip it.
_Avoid_: Welcome dialog, splash

**Tour version**:
The number recorded when a user finishes or skips the Tour; a user whose recorded version is lower than the current one is unseen and gets the Tour prompt.
_Avoid_: Seen flag, completed flag

**Unseen**:
The state of a user with no recorded Tour version, whether on a fresh install or an upgrade from before the Tour existed.
_Avoid_: First run, new user

**Scratch note**:
The unsaved document the Tour opens when none is open, built from the new-document template.
_Avoid_: Demo document, sample file
