What you get

Everything a writing tool needs. Nothing it doesn't.

  • 01

    Live split preview

    Switch between editor, split and preview with one click.

  • 02

    Outline of your headings

    A navigable outline of the document, so long files stay easy to move around.

  • 03

    Find and replace

    Search with case, whole-word and regex options, and replace across the document.

  • 04

    Slash commands and a formatting toolbar

    Insert headings, lists, tables and code blocks without remembering the syntax.

  • 05

    Tabs and recent files

    Keep several documents open, and jump back into what you were working on.

  • 06

    Native and local

    A Tauri and Rust app that opens and saves plain .md files with native Windows dialogs. Your files never leave your machine.

Download

Install Markora in under a minute.

Free and open source. A standard Windows installer, no account needed.

Download Markora (latest) .msi

Windows 10 / 11 · 64-bit MSI installer

Need an older build? See all versions or the GitHub releases.

  1. Download the .msiSave it anywhere. It is the only file you need.
  2. Double-click to installFollow the installer. It takes a few seconds.
  3. Open any .md fileLaunch Markora from the Start menu, or press Ctrl+O to open a file.

Seeing a SmartScreen prompt? If Windows shows "Windows protected your PC" for a new release, choose More info, then Run anyway. The installer is built and signed by a GitHub Actions workflow in the public repository.
